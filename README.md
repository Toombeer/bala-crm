# BALA CRM

CRM для детских центров, кружков и секций: сайт продукта и само приложение.

- Сайт: https://toombeer.github.io/bala-crm/
- Приложение: https://toombeer.github.io/bala-crm/app/

## Приложение (`app/`)
Расписание и журнал, ученики и семьи, абонементы, заявки и воронка, задачи и автоматизация,
шаблоны сообщений в WhatsApp, счета и оплаты (ссылка Kaspi, наличные со сдачей, перевод), долги,
расходы, прибыль и налог, выгрузка в Excel, закупки с динамикой цен, калькулятор, курсы валют НБ РК,
аналитика, сотрудники, история клиента. Работает на телефоне как приложение и без интернета.

Данные хранятся только на устройстве (localStorage). Резервная копия: Настройки → «Сохранить резервную копию».
При первом запуске в том же браузере приложение предлагает перенести данные из «Умного Зайки».

## Сайт
Страницы собирает `scripts/build_site.py` (общие шапка и подвал), стили лежат в `assets/site.css`.
Номер WhatsApp для заявок на облачные тарифы задаётся в `assets/site.js` (`CONTACT_WA`).

## Курсы валют
`.github/workflows/rates.yml` каждый день в 06:30 по времени Казахстана запускает `scripts/update_rates.py`,
который обновляет `app/rates.json` по данным Национального банка РК.
