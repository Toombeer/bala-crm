# BALA CRM — сервер

Бэкенд и веб-клиент CRM для детских центров: REST API, база данных, вход по паролю, роли сотрудников,
несколько центров на одном сервере, кабинет родителя, автоматизация воронки, отчёты, курсы НБ РК.

## Стек

| Слой | Технология |
| --- | --- |
| HTTP и маршрутизация | [Starlette](https://www.starlette.io/) (ASGI, на ней же построен FastAPI) |
| Сервер приложений | Uvicorn |
| Проверка данных | Pydantic v2 (схемы в `bala/schemas.py`) |
| Авторизация | JWT (PyJWT, HS256), пароли — scrypt из стандартной библиотеки |
| База данных | SQLite в режиме WAL, миграции SQL в `bala/migrations/` |
| Веб-клиент | Ванильный JS без сборки (`web/`), работает как PWA |
| Документация API | OpenAPI 3.1 из описаний эндпоинтов, Swagger UI на `/api/docs` |
| Тесты | pytest + Starlette TestClient |
| Развёртывание | Docker, docker-compose, Caddy (автоматический HTTPS) |

## Структура

```
server/
  bala/
    app.py          сборка приложения: маршруты, документация, веб-клиент, заголовки безопасности
    core.py         декоратор @api, контекст запроса, проверка токена и прав, генерация OpenAPI
    config.py       настройки из переменных окружения
    db.py           подключение, транзакции, миграции
    security.py     пароли, токены, права ролей
    schemas.py      схемы входных данных (Pydantic)
    services.py     бизнес-логика: оплаты по счетам, журнал, воронка, автоматизация, импорт
    rates.py        загрузка курсов Национального банка РК
    demo.py         демо-центр
    api/            эндпоинты: auth, resources, work, money, data
    migrations/     SQL-миграции
  web/              веб-клиент (раздаётся сервером на /)
  tests/            автотесты API
  scripts/          резервная копия базы, генерация документации API
  docs/API.md       список всех эндпоинтов (генерируется)
```

## Запуск для разработки

Нужен Python 3.12+.

```bash
cd server
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
python -m uvicorn bala.app:app --reload --port 8000
```

Откройте http://localhost:8000. Там можно зарегистрировать центр, загрузить демо-данные, добавить сотрудников и войти под ними в другом браузере.
Документация API: http://localhost:8000/api/docs.

Тесты:

```bash
python -m pytest -q
```

Обновить `docs/API.md` и `docs/openapi.json` после изменения эндпоинтов:

```bash
python scripts/gen_api_docs.py
```

## Как устроен API

- Все эндпоинты объявляются декоратором `@api(метод, путь, cap=право, body=Схема, summary=...)`. Из этого же описания строится документация.
- Каждый запрос получает `ctx`: подключение к базе, текущего пользователя, его центр (`ctx.org`) и права.
- **Изоляция центров:** любой запрос к данным фильтруется по `org_id` пользователя; чужие записи возвращают 404.
- **Права:** у роли есть набор возможностей (`read`, `attendance`, `students`, `groups`, `leads`, `tasks`, `billing`, `finance`, `settings`, `staff`, `data`). Таблица ролей в `docs/API.md`.
- **Отзыв доступа:** у пользователя есть `token_version`. Смена пароля, роли или отключение увеличивают её, и старые токены перестают работать.
- **Деньги:** счёт (`invoices`) — сколько семья должна, оплата (`payments`) — сколько внесла. Оплаты распределяются по счетам от старых к новым. Полностью оплаченный счёт один раз добавляет занятия детям из счёта.
- **Журнал:** «был» и «опоздал» списывают занятие, снятие отметки возвращает его. Пропуск и малый остаток запускают правила автоматизации.
- **Автоматизация:** правило «событие → задача (через N дней) + шаблон сообщения». События: этапы заявки, пропуск, остаток ≤ 2, выставлен счёт.
- **Кабинет родителя:** `GET /api/v1/public/family/{token}` без входа, по секретной ссылке. Ссылку можно перевыпустить.
- **Курсы валют:** фоновая задача раз в 6 часов загружает RSS Нацбанка; при пустой базе — историю за 30 дней.

## Развёртывание на сервере

Подойдёт любой VPS с Docker (1 vCPU, 1 ГБ RAM для начала). Данные детей — персональные данные: выбирайте сервер, физически расположенный в Казахстане.

```bash
git clone https://github.com/Toombeer/bala-crm && cd bala-crm/server
cp .env.example .env
# заполните BALA_SECRET и DOMAIN, направьте DNS домена на IP сервера
docker compose up -d --build
```

Caddy сам получит HTTPS-сертификат для `DOMAIN`. Проверка: `https://ваш-домен/api/v1/health`.

Резервные копии каждую ночь (crontab на сервере):

```
0 3 * * * cd /path/bala-crm/server && docker compose exec -T app python scripts/backup.py /data/backups
```

Копируйте папку резервных копий за пределы сервера (например, в облачное хранилище).
